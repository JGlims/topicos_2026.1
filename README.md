I am **Joao**, a Computer Engineering student currently transitioning into Computer Science. This repository serves as a technical log of my journey through signal processing, from sampling theory to complex physiological system identification.

* **Primary Language:** MATLAB / GNU Octave (GUI)
* **Key Packages:** `signal`, `control`
* **Automation:** Managed via a custom `.octaverc` startup script for local optimization.
* **Hardware Compatibility:** All scripts are tested for cross-compatibility with UnB's **LCCC-ULEG - Sala 2** laboratory computers.
